### Инварианты: их нельзя ломать

1. **Занятость гарантирует база.** Два `EXCLUDE`: по единице ресурса и по клиенту на всю сеть. Аренда комнаты пишет строки на все её единицы. Единицы блокируются `FOR NO KEY UPDATE`, ресурс `FOR SHARE`, блокировка ресурса `FOR UPDATE` (K6).
2. **Журнал операций только на вставку (K3, ADR 0004).** Правка значит сторно. Суммы в `bigint` минорных единицах. Баланс пишет только триггер.
3. **Единый порядок блокировок счетов.** Все счета одной транзакции берутся одним `lockAccounts` по возрастанию id, иначе взаимные блокировки.
4. **Идемпотентность в транзакции команды.** Повтор с тем же ключом отдаёт прежний ответ, с другим телом даёт конфликт.
5. **Вторичное не откатывает основное.** Уведомления и отчёты идут через outbox и pg-boss с повторами.
6. **Одно «сейчас» на команду.** `$now` приходит из `Clock`, не из `now()` в SQL (ADR 0003). Интервалы полуоткрытые, хранение в UTC, у филиала своя IANA-зона.
7. **Права только на сервере (K1, ADR 0005).** Роль × зона × действие. Чужой объект отвечает 404, как несуществующий. Неуказанное право запрещено.
8. **Отчёты читают только `rpt_*`.** Роль БД `yu_reports` с `default_transaction_read_only` и отдельным пулом.
9. **Ничего значимого не удаляется.** Архив вместо удаления, снимки цены и состава в операции.
10. **Пул БД обязан иметь `.on('error')`.** Страж: `tests/core/pool-error-handler.test.ts`.

### Миграции

Раннер требует строгий порядок номеров (`db/migrate.ts`). Потоки Э3 и Э4 писали параллельно, поэтому на стенде база пересоздаётся: `deploy.sh --reset-stage`. **Перед первым боем порядок 03xx и 04xx надо выстроить один раз** (план 6.5.1, техдолг 1.7). После этого только новые номера.

## 4. Как запустить

```bash
# Node 26, версия указана в package.json. npm ci ставит embedded-postgres.
npm ci
npm run typecheck && npm run lint
npm run build:crm && npm run build:site

npx vitest run --maxWorkers=4    # бэкенд на настоящей Postgres
npm run test:crm                 # экраны CRM на моке API
npm run test:site                # сайт
npm run load:race                # гонки броней; load:money, load:club
npm run test:e2e:stand           # сквозной: нужны SITE_URL и CRM_URL стенда
```

Разработка: `deploy/compose.dev.yml` (Postgres), `npm run dev:api`, `npm run dev -w @yu/crm`. Экран без API: `npm run mock -w @yu/crm` и `API_URL` на его порт. Выкладка и переменные окружения: `deploy/deploy.sh`, `deploy/compose.yml`, `apps/api/src/config.ts`.

Проверка данных после работы системы: ночная сверка, `node apps/api/src/modules/reports/reconcile.ts`, код выхода 0 значит расхождений нет.
