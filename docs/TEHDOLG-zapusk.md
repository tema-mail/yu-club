# Техдолг для запуска в бой

Документ для команды заказчика: что сделать, чтобы вывести Ю-Клуб в бой. Код системы готов к запуску, но всё ниже требует решений, ключей, серверов или юридических текстов заказчика. Разработка это не делает: значения, которые здесь названы, – по умолчанию для стенда.

Ведётся по ходу разработки: каждый этап добавляет сюда свои пункты. Статусы: **нужно** – без этого в бой нельзя; **желательно** – можно запустить и доделать позже.
