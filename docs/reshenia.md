# Реестр решений yu-club

Шаблон – 20 §11. Статусы 20 §11: открыт / утверждён / внесён / реализован / проверен; плюс «принято по умолчанию» – ответа заказчика нет, работаем по предложению плана (план, раздел 2; `docs/voprosy-zakazchiku.md`). Решение по умолчанию меняется ответом заказчика – правкой профильного контракта, настройки или `MATRIX`, как указано в колонке «Как меняется».

Колонки «Дата» и «Кто утвердил» у решений по умолчанию – дата внесения и техлид; утверждения заказчика нет. Тест – шаг плана 6.4, который проверяет поведение.
